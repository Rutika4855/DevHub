🐙 Git Helper

Common Git commands for managing your projects.

Initialize Repository

Creates a new Git repository in your project folder.

git init

Check Status

Shows modified, added and untracked files.

git status

Add Files

Adds all changed files to the staging area.

git add .

Commit Changes

Saves your staged changes with a message.

git commit -m "Your message"

Push Changes

Uploads local commits to the remote repository.

git push origin main

Pull Changes

Downloads the latest changes from the remote repository.

git pull origin main

Clone Repository

Downloads an existing repository from GitHub.

git clone repository-url

Create Branch

Creates a new Git branch.

git branch feature-name
